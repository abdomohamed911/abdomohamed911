<summary><h3 align="center">How to Enable Snake Animation</h3></summary>

<br>

To activate the snake contribution animation on your profile, you need to set up a GitHub Action in a separate repository. Follow these steps:

1. Create a new repository named exactly **abdomohamed911** (matching your username)
2. Add the following GitHub Action workflow to `.github/workflows/snake.yml`:

```yaml
name: Generate Snake
on:
  schedule:
    - cron: "0 0 * * *"  # Runs daily at midnight UTC
  workflow_dispatch:

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - name: Generate snake game from GitHub contribution graph
        uses: Platane/snk/svg-only@v3
        with:
          github_user_name: abdomohamed911
          outputs: |
            dist/github-snake.svg
            dist/github-snake-dark.svg?palette=github-dark

      - name: Push to output branch
        uses: crazy-max/ghaction-github-pages@v4
        with:
          target_branch: output
          build_dir: dist
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
```

3. Commit and push the workflow file. After the action runs, the snake SVGs will be available in the `output` branch.
